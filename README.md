# Kriti Sharma - Personal Developer Portfolio

A modern, high-performance developer portfolio built for **Kriti Sharma**, Full Stack Java Developer.

## 🚀 Live Preview & Running Locally

Because this project is built with clean HTML5, Tailwind CSS, and vanilla JavaScript, there is **no build step required**. You can view it instantly in two ways:

### Option 1: Direct Open
Simply double-click `index.html` in your file explorer, or open it in any web browser.

### Option 2: Local HTTP Server (Recommended)
From this directory, run:
```bash
# Python 3
python -m http.server 8000
```
Then visit: `http://localhost:8000`

## 🌐 Free 1-Click Deployment

### Deploy to GitHub Pages:
1. Create a repository on GitHub (e.g. `Kritisharma26/portfolio` or `Kritisharma26.github.io`).
2. Push this folder's contents to the repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/Kritisharma26/portfolio.git
   git push -u origin main
   ```
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Under **Source**, select `main` branch and `/ (root)`, then click **Save**.
5. Your portfolio will be live at `https://Kritisharma26.github.io/portfolio`!
